# Themer - The Chaos Theme Switcher :D

Automatically switch VSCode themes at custom intervals!

## Features
- Auto-switch themes every 1-60 seconds
- Sequential or random mode
- Select your favorite themes
- Flashbang mode (* _ *)

## Commands
- `Themer: Configure Madness` - Setup themes and interval
- `Themer: Let the Chaos Begin!` - Start switching
- `Themer: Restore Sanity` - Stop switching
- `Themer: FLASHBANG MODE!` - White flash every 3s
