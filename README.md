## Commands
- `Themer: Configure Madness` - Setup themes and interval
- `Themer: Let the Chaos Begin!` - Start switching
- `Themer: Restore Sanity` - Stop switching
- `Themer: FLASHBANG MODE!` - White flash every 3s
